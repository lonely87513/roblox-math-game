## 玩法說明

1. 在「數字位數」選擇 **2 位數／3 位數／4 位數**。
2. 在「題目類型」選擇題目形式：
   - **求結果**：`4321 + 2876 = ?`
   - **求被加／減數**：`? - 2876 = 7197`
   - **求加／減數**：`4321 + ? = 7197`
   - **隨機**：每一題隨機決定其中一種形式。
3. 按「🚀 開始挑戰！」開始，畫面會顯示算式與計時器。
4. 輸入答案後按「✅ 確定」，或在答案欄按 Enter 送出；也可以直接使用畫面上的數字鍵盤作答。
5. 答對會加分、累積經驗值並播放慶祝動畫；答錯會記錄一次錯誤並將連勝歸零，之後自動進入下一題。
6. 按「💡 提示」可查看逐步提示（提示文字為繁體中文，會分行顯示）。
7. 按「🚀 開始挑戰！」可重新開始一局；經驗值與等級會保留，分數與連勝會歸零。

加減法各佔一半機率；被減數永遠大於減數，因此不會出現負數答案。

## 計分、經驗值與等級

| 項目 | 規則 |
| --- | --- |
| 答對得分 | `10 + 連勝 × 2` |
| 答對經驗值 | `10 + ⌊連勝 ÷ 3⌋ × 5` |
| 升級門檻 | `等級 × 100` 經驗值 |
| 升級 | 經驗值達門檻時等級 +1，扣除該門檻的經驗值 |
| 答錯 | 錯誤數 +1，連勝歸零 |
| 連勝音效 | 連勝達 3 連時播放 |
| 每局記錄 | 保留最近 5 局的分數、正確／錯誤數與用時 |

## 介面與無障礙

- **響應式版面**：手機為單欄；闊螢幕（≥ 1024px）改為兩欄，主欄放題目與鍵盤，側欄放等級、進度條、計分板與設定，記錄區橫跨整個版面。
- **流體字級**：所有字級改用 `rem` + `clamp()`，視窗寬度與使用者字體設定都會即時生效；已完全移除 `em` 字級，避免父子層疊乘。
- **深色模式**：跟隨系統的 `prefers-color-scheme`，並提供 `prefers-reduced-motion` 支援（會停用彩帶與粒子動畫）。
- **觸控與鍵盤**：所有可按 element 至少 44 × 44 px，具備 hover／`:focus-visible`／`:disabled` 狀態；答案欄可用 Enter 送出。
- **安全區**：iPhone 瀏海機型使用 `env(safe-area-inset-*)` 內距（需 `viewport-fit=cover`）。
- **無障礙標記**：算式為 `role="status"`、進度條為 `role="progressbar"`、數字鍵盤有群組標籤、選項按鈕帶 `aria-pressed`。

## 本地開發

整個遊戲就是 `index.html` 一個檔案，沒有建置流程。

```bash
# 方式一：直接開啟檔案
open index.html          # macOS
xdg-open index.html      # Linux

# 方式二：用本機伺服器（建議，可測試 localStorage 行為）
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

修改檔案後重新整理瀏覽器即可看到效果。

## 部署到 GitHub Pages

此 repository 沒有 Actions workflow，GitHub Pages 直接由 **分支 `main` 的根目錄** 提供服務：

1. 在 repository 的 **Settings → Pages** 設定 **Source = Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`。
2. 每次把改動合併到 `main`，GitHub 會自動重新部署。
3. 線址為 <https://lonely87513.github.io/roblox-math-game/>。

因為是單檔部署，新增檔案時請確認不會影響根目錄的 `index.html`。

## 資料儲存

使用瀏覽器的 `localStorage`，只保存兩個 key：

| Key | 內容 |
| --- | --- |
| `robloxMath_xp` | 目前累積的經驗值（整數） |
| `robloxMath_level` | 目前等級（整數，最小為 1） |

讀寫都包在 `try/catch` 內：無痕模式、配額已滿或瀏覽器封閉儲存時，遊戲仍可正常進行，只是不會保存進度。

## 技術規格

- 單一 `index.html`，內聯全部 CSS 與 JavaScript（無框架、無 npm、無 CDN 程式庫）。
- 唯一的外部資源是既有的 Google Fonts 字型連結（`Fredoka One`、`Nunito`）；離線時會自動退回系統字型。
- 音效由 Web Audio API 即時產生，不使用音檔。
- 彩帶與粒子效果為純 CSS 動畫。

## 已知限制

- **遊戲記錄不會跨重新整理保留**：「過往 5 次遊戲記錄」只存在於目前頁面的記憶體，重新整理後即清空；經驗值與等級則會保留。
- **離線時字型會改變**：Google Fonts 無法載入時，標題與數字會改用系統字型，外觀略有差異。
- **音效需要使用者互動**：受瀏覽器自動播放政策限制，音效會在使用者第一次點擊或按鍵後才啟用。
- **一次最多升一級**：即使單次獲得的經驗值超過多級門檻，也只會升一級，餘下的經驗值保留至下一次答對。
- **進度不同裝置不同步**：經驗值與等級只存在於目前使用的瀏覽器。
- **答題時自動聚焦答案欄**：每次出新題都會自動聚焦答案欄，在手機上可能會彈出系統鍵盤。
